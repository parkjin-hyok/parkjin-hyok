## 03 / 글로벌 컴퓨팅 (GLOBAL COMPUTE)

공간 컴퓨팅, 엣지 지능, DePIN은 계산을 단일 추상 클라우드에서 기기, 센서, 노드, 네트워크, 기계 및 물리적 환경으로 이동시킵니다. 지구는 장식이 아닙니다. 그것은 끊임없이 연결된 물리적 세계의 운영 기반입니다.

## 04 / 에이전트 지능 (AGENTIC INTELLIGENCE)

### 모델은 생성한다. 에이전트는 운영한다.

모델은 단지 하나의 구성 요소일 뿐입니다. 진정한 엔지니어링은 그 주변에 존재합니다: 상태, 메모리, 컨텍스트, 계획, 도구 호출, 실행 및 검증.

**모델 → 라우터 → 컨텍스트 엔진 → 메모리 → 플래너 → 정책 → 도구(MCP) → 실행 → 관측 가능성 → 검증 ↺**

## 05 / 엔지니어링 원칙 (ENGINEERING PRINCIPLES)

*   **시스템으로 사고하라 (THINK IN SYSTEMS):** 기능은 런타임, 네트워크, 데이터 저장소, ID 계층 및 운영 피드백 루프 내에 존재합니다.
*   **루프로 사고하라 (THINK IN LOOPS):** 관찰 → 모델링 → 결정 → 실행 → 검증 → 관찰. 루프가 자체 출력을 측정할 수 없다면 안정적으로 적응할 수 없습니다.
*   **실패 모드를 설계하라 (THINK IN FAILURE MODES):** 네트워크는 분할되고, 노드는 사라지며, 상태는 오래됩니다. 아키텍처는 가정이 깨진 후에 발생할 일을 정의해야 합니다.
*   **가정보다 증거를 선호하라 (PREFER EVIDENCE):** 측정, 추적, 테스트, 프로파일링, 시뮬레이션, 검증. 확신은 관찰 가능한 행동에서 나와야 합니다.
